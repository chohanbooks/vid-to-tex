# YouTube Bilingual Transcriber (Groq + Streamlit)

A Streamlit web application that downloads YouTube video audio, transcribes it using **Groq's Whisper API** (with high accuracy for Urdu, English, and mixed conversational speech), and compiles the results into a downloadable Word document (`.docx`).

## Setup & Deployment
1. Upload these files (`app.py`, `requirements.txt`, `packages.txt`, `README.md`) to a GitHub repository.
2. Log in to [Streamlit Community Cloud](https://share.streamlit.io/) and deploy the repository.
3. Add your Groq API key in the Streamlit App **Secrets** dashboard:
   ```toml
   GROQ_API_KEY = "your-groq-api-key-here"
